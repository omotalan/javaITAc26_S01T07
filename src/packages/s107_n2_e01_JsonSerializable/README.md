# Json Serializable
**Descripció**: Sprint 1, Tasca 7, Nivells 2 i 3

## 📌 Nivell 2: Creació d’anotacions personalitzades + Nivell 3: Lectura d’anotacions amb Reflection
```

Nivell 2: Creació d’anotacions personalitzades

En aquest nivell faràs un pas més enllà creant la teva pròpia anotació. Aquesta anotació servirà per indicar que un objecte Java s’ha de serialitzar en format JSON, i rebrà com a paràmetre el directori de destinació. Començaràs a veure com les anotacions no només informen, sinó que poden afectar la lògica del programa quan s’interpreten amb eines addicionals.

Objectiu: Comprendre com es poden definir annotations personalitzades amb paràmetres per enriquir la funcionalitat del codi.
Exercici 1 - JSON Serialization

Crea una anotació personalitzada que ha de permetre serialitzar un objecte Java en un fitxer JSON. L’anotació ha de rebre el directori on es col·locarà el fitxer resultant.

Nivell 3: Lectura d’anotacions amb Reflection

En el nivell avançat utilitzaràs Java Reflection per detectar i actuar sobre anotacions personalitzades en temps d'execució. Aquesta tècnica és molt poderosa i sovint utilitzada per frameworks i biblioteques per modificar comportaments de manera dinàmica. Aquí veuràs com llegir una anotació i executar codi basat en la seva presència.

Important

Objectiu: Aplicar el concepte de Reflection per detectar i utilitzar annotations en temps real, assolint un nivell avançat d’abstracció i flexibilitat en el teu codi.
Exercici 1 - Java Reflection

Afegeix la possibilitat que l'anotació creada en el nivell anterior sigui registrada per la Virtual Machine en temps d'execució. Demostra que s'executa la lectura de l'annotation fent servir Java Reflection.

```

## ✨ Funcionalitats (si és aplicable)
Al crear l'anotació i aplicar la retention policy, la JVM ha de retenir metadades, cosa que és
necessària per aplicar la reflection. Dins la classe JsonSerializerProcessor jo demostro l'ús
de reflection al detectar i extraure l'anotació per mitjà de variables
